业务与统计规则 · 草稿

筛选范围企业筛选控制所有经营模块；时间筛选仅控制订单收益、订单趋势和企业主/员工期间指标。项目任务表现、项目使用情况、企业主排行不受时间筛选。
订单与收益订单笔数按创建时间与原始订单 ID 计，退款不删原单。收益为审核通过订单的推广收益，部分/全额退款按实际退款金额冲正并归回原订单创建日。线下收益全入企业主；线上按订单分成比例快照拆分企业主与员工账户。
订单趋势今日按小时，近 7 天按自然日，本月按整月日历日期，累计按月；跨年自定义区间按年。柱为净收益、线为原始新增订单笔数，分别使用左右轴。
企业主与员工右豹 ID 加白产生企业主；企业主邀请码绑定产生员工关系。全部企业看累计企业主和期间新增；单企看该企业主开通状态与时间。有效员工是期间有提词、回填或新增订单行为且当前未离职的员工。
项目任务表现顶部统计随品牌/海外 Tab 切换：品牌展示提词、回填和记录量比；海外展示成功申领、有效归因订单、净推广收益和订单/申领。列表统一展示具体项目名称与项目类型标签，海外项目另标申领载体。海外成功申领按实际次数计，不按员工或项目去重行为；全额退款扣除有效归因订单笔数，部分退款只冲金额。已移出同步的历史项目及记录仍保留。
项目使用情况只保留“当前同步项目 → 实际使用项目”两段；按项目 ID 去重。品牌项目提交提词/回填、海外项目成功申领即算使用；任一企业有行为，全平台该项目计 1 个。移出同步后退出，重新上线按本次上线时间重新统计。
企业主排行仅全部企业显示；按退款后净推广收益实时排序，提词、回填、有效订单笔数按员工任务或订单发生时的企业主归属汇总；全额退款的有效订单扣除，部分退款保留。
