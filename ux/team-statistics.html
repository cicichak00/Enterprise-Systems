前后端开发说明

页面与前端组件

首页组长列表点击“查看下级”进入独立团队统计页，带入组长 ID 与时间筛选。TeamFilters 负责时间和团队选择，TeamSummary 展示汇总，ContributionSection 分为组长与组员，PersonRow 身份信息按一行展示：脱敏昵称、用户 ID、状态；下方展示四项指标。组长身份标签与昵称、ID、状态同一行展示。时间与团队选择器使用日历、团队图标，保留选中值、下拉箭头及无障碍名称。昵称将第二个字符替换为 *（单字昵称替换该字），用户 ID 保持原值；脱敏规则应由后端统一执行，前端示例仅模拟效果。团队汇总说明放在卡片内底部。返回时恢复首页展开和滚动位置。

大额展示与预览

团队汇总与人员明细均保持一排四列。金额绝对值达到 10,000 元后以万为单位，保留两位小数，仅用于展示，不影响计算与汇总。点击任意金额显示带千分位的完整金额。订单笔数保持整数并加千分位。长数值不截断、不横向滚动；小屏仍保持四列，万级金额格式化并适当缩小字号。大额示例只改变原型数据，不代表真实业务。

字体规则

系统字体：-apple-system / BlinkMacSystemFont / PingFang SC / sans-serif。页面标题 23px / 650；团队标题 17px / 650；分区标题 13–14px / 600；姓名 13px / 600；汇总数值 19px / 650；个人数值 15px / 550；标签与辅助文案 11px / 400。行高 1.5–1.6，数字使用 tabular-nums。

色调规则

页面背景 #F7F8FA，明细白底 #FFFFFF；主文字 #30313A，辅助 #9294A3，分隔线 #F0F0F4；交互主色 #827DE0。汇总底色 #EEECFF → #F7F6FF，边框 #DEDBF7，数字 #625CBA。个人数字深色 #3D3E47。在职浅绿底 #EDF8F2、文字 #419372，同时保留状态文字。

布局与组件状态

4px 间距基准，内容边距 14px，卡片内边距 12–18px，卡片间距 10px，分区间距 22px，圆角 12px。汇总强调、个人明细弱化。默认四列，窄屏或长金额改两列，不截断金额。选择器触控区域至少 44px。加载用骨架屏；空列表显示“暂无下属组员”；无数据为 0，失败或未返回用“—”并提供重试。筛选触发整页刷新，过期响应不得覆盖新筛选结果。

金额使用分单位整数，前端转元显示两位小数。后端汇总全部人员，不能只累加当前页。团队汇总 = 组长贡献 + 全体组员贡献。统一 Asia/Shanghai 时区，时间区间左闭右开；团队切换保留时间。后端校验企业及团队访问权限，成员分页稳定排序。

口径待确认与验收

订单状态范围、按何种时间统计、退款处理、换组历史归属、离职员工历史统计、推广收益与企业及员工收益的关系，需产品和后端确认。原型为示例口径。验收包含团队和时间切换、零订单、空组员、分页汇总、长昵称大金额、失败重试及请求乱序，适配 320 / 375 / 430px。
