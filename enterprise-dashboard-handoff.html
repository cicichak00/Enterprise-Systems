业务与统计规则

六个模块的口径

企业主开通截至周期末有效加白的右豹用户 ID 数；周期新增按加白生效时间。加白是企业号权限开通，不计作邀请新增用户。
邀请新增用户统计周期内由企业主邀请、成功加入企业的员工右豹 ID 去重数；邀请只是建立归属关系的路径，不另设用户来源分类。重复邀请或未绑定成功不计入。
任务提词 / 回填分别按成功提交的关键词记录 ID、回填记录 ID 计数；登录、浏览、失败和取消记录不计入。
订单笔数 / 收益新增订单按订单创建时间和订单 ID 去重计笔数，创建一单即新增一笔；推广收益仅计审核通过且未退款的有效订单，按原订单创建日展示。晚审核会回填历史日期；退款或作废按原单冲销，分成用订单确认时快照。
项目使用占比在当前企业筛选范围内，分母为截至周期末可归属的右豹来源项目 ID 数；分子为其中周期内至少有一次成功提词或回填的项目 ID 数。占比 = 分子 ÷ 分母；分母为 0 时显示“—”。逐企业明细的同步项目按企业—项目关系去重，使用项目是其中周期内有成功任务行为的项目；跨企业项目可能复用，明细行不可直接相加作全局去重数。
企业主排行汇总企业主名下员工在周期内的提词、回填、有效订单及订单推广收益；事件发生时的员工归属快照决定企业主，离职不回溯扣减历史。按推广收益金额降序。

订单金额与入账

  • 线下结算：订单推广收益全额入企业主账户；平台不拆分员工入账。
  • 线上结算：根据订单确认时的员工分成比例，将一笔订单拆成企业主与员工两笔入账。
  • 看板的“订单金额 / 收益”是订单推广收益，不是企业主入账；全量推广收益 = 企业主入账 + 员工入账（冲销后净额）。

筛选与对比

  • 默认本月：北京时间当月 1 日至最新数据截止日；企业筛选控制全部模块。此交互稿仅提供 2026-09-01 至 2026-09-12 的示例数据，正式环境按所选周期请求接口。
  • 周期指标与上一等长周期比较；累计存量指标对比上月末。示例值仅演示结构，不代表真实业务表现。

核对约束

  • 同一企业筛选和日期窗口必须应用于全部周期指标；存量指标使用结束日快照。
  • 订单归属、结算方式和分成比例以订单快照为准，不读取员工当前配置重算历史。
  • 排行金额是订单推广收益；企业主和员工入账是该收益的分配，避免重复相加。
  • 生产环境无数据展示空态；本交互稿所有数值都是演示数据。
