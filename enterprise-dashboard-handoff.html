统计规则说明

筛选与时间

  • 企业筛选控制整张看板；时间快捷项包含当天，自定义时间按北京时间自然日统计。
  • 趋势百分比与紧邻的上一等长完整周期对比；当天未结束时，对比昨日相同截止时刻；累计不展示环比。
  • 查询使用最后一次完成汇总的数据，不改变页面展示的数据更新时间。
  • 选择“全部企业”展示企业健康度和企业排行；选择单个企业后隐藏平台汇总，聚焦该企业员工、项目和收益。

指标口径

企业号用户企业号用户仅分为企业主和企业员工，按右豹用户 ID 去重；已退出企业的员工不计当前总数。
新增员工按用户首次成为该企业员工的时间统计；邀请码是员工加入企业的一种来源路径，不形成独立用户类型，也不与企业员工重复累计。
活跃员工/活跃率周期内至少完成一次有效提词或回填的去重员工；活跃率＝活跃员工数÷周期内在职且具备提词或回填权限的员工数。
有效提词/回填提词按成功生成结果的操作次数统计；回填按成功提交的记录数统计，失败、取消或已删除数据不计入。
漏斗转化率每一步转化率＝本阶段去重员工数÷上一阶段去重员工数；上一阶段为 0 时显示“—”。
项目使用实际提词项目为周期内至少发生一次有效提词的上线项目；项目覆盖率＝实际提词项目÷周期内具备使用条件的上线项目。
订单收益仅含审核通过且未退款、未作废的订单；订单总收益＝企业主收益＋员工收益。

异常判定

  • 低活跃：企业连续 7 个自然日活跃率低于 10%。
  • 低回填：有效回填员工数÷有效提词员工数低于 20%。
  • 收益下降：本周期有效订单收益较上一等长周期下降超过 30%。阈值建议后续支持配置。

导出

按当前企业与时间范围导出 Excel，包含企业健康、员工新增及来源、行为活跃、项目使用、订单收益五个工作表，仅后台管理员可操作。

开发对接说明

建议接口

看板汇总GET /enterprise/dashboard/summary?enterprise_id=&start_date=&end_date=
趋势数据GET /enterprise/dashboard/trends，返回日期维度的新增、活跃、提词和回填序列。
项目排行GET /enterprise/dashboard/projects，支持分页与收益排序。
导出任务POST /enterprise/dashboard/export，异步返回任务 ID；完成后提供下载地址。

交互状态

  • 筛选变化后点击查询统一刷新所有卡片；请求期间展示局部骨架屏并禁用查询按钮。
  • 接口失败保留上一次成功数据并展示错误提示；无数据时图表、指标和表格均需独立空状态。
  • 明细入口跳转现有模块并携带 enterprise_id、start_date、end_date。
  • 金额统一保留两位小数，人数和次数使用千分位，除数为 0 时比率显示“—”。
