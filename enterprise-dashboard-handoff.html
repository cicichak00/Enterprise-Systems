业务与统计规则

六个模块的口径

企业主开通右豹用户经 ID 加白后只获得企业主身份；截至周期末按有效加白的企业主右豹 ID 去重，周期新增按加白生效时间。不把加白计作新增员工。
邀请加入与有效员工企业主通过企业号邀请码邀请，员工成功绑定到该企业主后计入本月邀请成功人数，按员工右豹 ID 去重。将这批受邀员工按截止时状态分为“仍在职”和“已离职”两组，两组之和等于邀请成功人数；离职表示员工与企业主关系解除。有效员工是这批受邀员工中，本期至少成功提词、回填或新建订单者，可包含后来离职者；有效员工是子集，不与两种状态相加。历史行为保留。
项目任务表现提词和回填分别按成功提交的记录 ID 计数，项目行按任务发生时的项目 ID 汇总。回填 / 提词为记录量比值，不是人员转化率；登录、浏览、失败和取消记录不计入。
订单笔数 / 收益新增订单按订单创建时间和订单 ID 去重计笔数，创建一单即新增一笔；推广收益仅计审核通过且未退款的有效订单，按原订单创建日展示。晚审核会回填历史日期；退款或作废按原单冲销，分成用订单确认时快照。组合图左右轴单位不同，仅比较各自走势。
项目使用路径来源项目、已上线、已同步企业、实际使用依次展示；在当前企业筛选范围内均按项目 ID 去重。已同步表示项目与企业已建立关联；实际使用指周期内至少成功提词或回填一次。核心占比 = 实际使用 ÷ 来源项目；分母为 0 时显示“—”。逐企业明细按企业—项目关系去重，跨企业项目复用时不可直接加总。
企业主排行汇总企业主名下员工在周期内的提词、回填、有效订单及订单推广收益；事件发生时的员工归属快照决定企业主，离职不回溯扣减历史。按推广收益金额降序，以横向条形比较收益差距。

订单金额与入账

  • 线下结算：订单推广收益全额入企业主账户；平台不拆分员工入账。
  • 线上结算：根据订单确认时的员工分成比例，将一笔订单拆成企业主与员工两笔入账。
  • 看板的“订单金额 / 收益”是订单推广收益，不是企业主入账；全量推广收益 = 企业主入账 + 员工入账（冲销后净额）。

筛选与对比

  • 默认本月：北京时间当月 1 日至最新数据截止日；企业筛选控制全部模块。此交互稿仅提供 2026-09-01 至 2026-09-12 的示例数据，正式环境按所选周期请求接口。
  • 周期指标与上一等长周期比较；累计存量指标对比上月末。示例值仅演示结构，不代表真实业务表现。

建议数据接口

概览与收益GET /enterprise/dashboard/summary：allowlisted_owner_count、new_owner_count、invited_staff_count、invited_still_bound_count、invited_departed_count、effective_invited_staff_count、active_staff_count、keyword_count、backfill_count、created_order_count、promotion_revenue、owner_credit、staff_credit。受邀员工在职与离职之和等于邀请成功总数；有效员工为其行为子集。

项目任务GET /enterprise/dashboard/project-tasks：project_id、project_name、keyword_count、backfill_count；项目行按成功任务记录归属汇总，正式环境按项目量排序分页，本页仅为示例。

核对约束

  • 同一企业筛选和日期窗口必须应用于全部周期指标；存量指标使用结束日快照。
  • 订单归属、结算方式和分成比例以订单快照为准，不读取员工当前配置重算历史。
  • 排行金额是订单推广收益；企业主和员工入账是该收益的分配，避免重复相加。
  • 生产环境无数据展示空态；本交互稿所有数值都是演示数据。
