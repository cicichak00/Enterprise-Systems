没有匹配的工具
UX 演示：支持编辑、筛选、调整排序、启用 / 停用。数据只保留在当前页面，不会写入真实后台。

后台开发需求

配置项、保存规则和接口要求放在此页。

配置哪些内容
工具标识
唯一且不可重复，创建后不可修改。
前端名称
必填，建议 2–6 个汉字。
图标
上传 PNG / JPG / WebP，≤2MB，建议 128×128px 方图；支持预览、替换和移除。
前端展示位置
单选企业主或员工；一个工具仅允许一个位置。
跳转配置
每个工具仅一个跳转配置，随选定位置生效。
注意事项
选填，首页不显示；目标页使用说明或外链打开前展示。
排序
非负整数，大值靠前，同值按工具标识排序。
企业范围
全部企业 / 指定企业；指定企业不能为空。
状态
新建默认停用。配置有效后才可启用。
前端调整事项
  • 列表：支持名称 / 标识搜索、展示位置和状态筛选；排序值从大到小排列。
  • 表单：新增 / 编辑共用表单，标签与必填星号同行；弹窗头尾固定，仅表单内容滚动。错误提示不清空输入。
  • 图标：提供上传、预览、替换、移除；校验格式和 2MB 限制，上传中禁用保存。
  • 展示位置：企业主 / 员工单选，只显示一组跳转配置。切换后清除未选位置的提交字段。
  • 排序点外或回车保存；启用 / 停用前确认影响，成功后刷新有效列表。
  • 保存时禁止重复提交；失败保留表单内容并可重试。
后端调整事项
  • 提供工具列表、详情、新增、编辑、状态和排序保存接口，具体路径联调确认。
  • 字段：tool_key / name / icon_url / display_position / target_type / target / notice / sort / enterprise_scope / enabled / version。
  • 上传接口校验真实文件类型与体积，成功返回素材 ID 和图标 URL；保存仅引用上传成功的素材。上传失败不覆盖旧图标，上传期间禁止保存。
  • 字段校验：display_position 只接受 owner 或 employee；必填名称、图标、链接、排序在服务端再次校验。
  • 排序：sort 降序，同值按 tool_key 升序；列表与前端有效工具接口一致。
  • 内部链接校验已注册页面；外部链接校验 HTTPS 与允许域名。
  • 平台启用、企业范围、前端展示位置、员工独立授权共同计算最终可见权限。
  • 企业主自用与员工授权分开。组合提词、快捷提词拆成独立权限并兼容旧数据迁移。
  • 记录变更人、时间、修改前后值；按版本处理并发冲突，返回最终保存结果。
  • 停用后入口和目标接口均失效；修改配置不得绕过权限鉴定。
权限与异常
  • 仅平台后台有权人员可维护工具，企业主不能修改平台配置。
  • 员工工具授权仍由企业主在所属企业内操作。
  • 企业选择使用企业 ID，服务端校验企业存在及操作权限，不能仅保存显示名称。
  • 网络失败、链接错误、版本冲突分别提示；正式环境不使用本页内存演示数据。
