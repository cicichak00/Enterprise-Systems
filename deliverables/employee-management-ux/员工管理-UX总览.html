页面形式设置首页展示当前员工、当前值和配置入口；各功能使用独立页面，不使用管理悬浮层。

03

进阶管理

进阶管理 → 开启 → 选身份 → 选关联 → 分成 / 权限 → 确认

‹ 返回　进阶管理

进阶管理　　　　　　　　　开关
身份　小组长 / 组员
关联　选择组员 / 所属小组长　›
个人分成比例　　　　　　　60%
小组长可设置组员分成及查看权限
确认
三种身份关闭进阶管理为普通员工；开启后选择小组长或组员。仅作用于保存后的新订单。
小组长可关联多名在职普通员工；配置个人分成、该小组组员分成及名下组员订单 / 收益 / 统计查看权限。
组员必须且只能关联一名在职小组长；组员个人分成不得高于所属小组长个人分成。
候选限制本人、其他小组长、归属其他小组长的组员及离职员工不可新增为组员，展示禁用原因。
身份切换已有组员的小组长须先解绑全部组员并保存，再关闭进阶管理或切换身份。解除关联的组员在本稿恢复普通员工。
关联同步保存后组长人数、成员身份与所属关系同步更新；关联选择返回时保留配置草稿。

分类布局左侧按类型分类，右侧展示对应项目和当前权限；新增项目归入对应分类。

下一步
先选员工点击批量操作后进入列表多选；默认收起经营指标，0 人不能进入下一步。搜索保留已选员工。

确认普通批量表单先确认操作对象和内容再保存；项目使用按分类变更预览；仅修改本次选定字段。
进阶边界进阶身份和关联按单员工配置，不提供批量建立组长与组员关系。

基础配置规则

设置项 → 修改值 → 核对范围 → 确认

‹ 返回　基础配置规则

常规分成　　　0–100%
标签　　　　　1–5 个字符
结算方式　　　线上 / 线下
快捷提词 / 收益数据 / 钱包
确认
展示标签1–5 个字符，仅修改展示文字；不改变真实身份、关系及分成。批量支持统一自定义或恢复系统标签。
结算方式线上 / 线下结算独立于分成比例；批量仅对未设置者开放。已设置员工是否可修改须按正式业务接口确认。
快捷提词控制员工字节项目快捷提词组件，默认关闭。
收益数据控制员工查看自己的收益数据，不改变实际收益。
钱包仅线上结算员工可开启；线下结算关闭且不可开启。支付、提现的细分能力由实际接口确定。
