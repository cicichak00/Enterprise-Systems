# 功能规则与页面对照

最新页面形式以《录屏管理页面-最终形式说明》为准：单员工使用员工权限/项目管理页签浮层，批量使用功能专属表单。旧独立设置页已撤回。

当前范围以《员工管理-整合确认说明》为准。页面需要体现适用对象、输入校验、状态变化和保存后的反馈，不能仅将规则放在说明文档里。

| 页面 | 当前对应规则与显示 |
| --- | --- |
| 员工列表 | 固定六项指标；真实身份和展示标签分别展示；加入时间、结算、ID 按已确认位置显示；排序保持员工 ID 和数据对应关系 |
| 批量选择 | 先选员工；0 人不能继续；进入多选收起指标；搜索保留已选对象；设置首页显示目标名单 |
| 常规分成 | 仅普通员工适用；进阶身份引导到进阶管理；比例必填且在 0–100；确认显示每名员工修改前后数值 |
| 结算方式 | 线上/线下结算；不改变分成比例；确认目标员工与前后状态 |
| 展示标签 | 修改姓名旁展示文字，不变更真实角色与权限；不能为空，按新录屏限定 1–5 个字符 |
| 快捷提词 | 对应字节项目快捷提词组件；默认关闭；说明与开关状态放在该项设置页 |
| 收益数据 | 控制员工查看自己的收益数据，不改变实际收益 |
| 钱包权限 | 明确只作用于当前员工/所选员工；更细的支付、提现能力需实际接口规则确认，不推断为总开关可涵盖全部能力 |
| 进阶管理 | 三身份互斥；小组长多名组员、组员唯一小组长；本人/其他组长/他人组员禁选；有成员的小组长先解绑再换身份 |
| 关联与分成 | 组员分成不高于所属组长；新增/解除关联前预览双方身份变化；保存后名单和归属同步更新 |
| 项目配置 | 分类默认展开并可折叠；搜索自动展开；混合配置明确显示；只保存指定项目变更，其他项目不变；离开未保存内容可继续或放弃 |

原型不连接服务端。离职校验、分页选择、并发关系更新、部分失败重试等正式实现要求，以整合说明中列明的范围为准；原型没有覆盖的异常场景不能标为完成。

README 中曾提到的“组长出单链接、小组分类与全组出单、每月推广收益”缺少在本轮统一说明中的对应细则，属于待核对范围，不能声称已合并完成。
