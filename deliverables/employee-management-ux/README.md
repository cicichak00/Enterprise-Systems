# 员工管理 UX 原型

打开 [员工管理整合稿](员工管理-整合确认稿.html) 可直接交互，无需安装依赖。

## 当前确认版本

- 单员工：员工列表 → 管理 → 独立设置页 → 对应功能配置 → 确认。
- 批量：批量操作 → 勾选员工 → 下一步 → 选择操作 → 配置 → 确认。保留选择，不符合规则的操作禁用并说明原因。
- 项目：左侧分类、右侧项目及当前权限；支持搜索、跨分类多选、当前结果全选、统一可用/禁用，保存前按分类确认变更，未操作项目保持原配置。
- 进阶管理独立配置身份、关联、进阶分成及小组长查看权限；常规分成比例使用独立页面，进阶身份显示不适用。
- 员工卡片固定展示六项指标，已取消自定义指标需求。昵称后显示 ID，结算方式与标签同行，加入时间在标签下方。
